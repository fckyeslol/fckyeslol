My work is centered on backend development and neural networks using Python and PyTorch. I’m interested in how systems behave under real constraints: performance, data flow, and reliability. I focus on building solutions that are not only functional, but measurable and scalable.

I’ve developed multiple machine learning projects, mainly around classification and data-driven models, working through the full pipeline from data processing to model design and evaluation. In parallel, I’ve built web platforms for enterprises and NGOs, handling both backend logic and system structure. I also built a 2D game in Godot as a side project to explore real-time systems and interaction.

More recently, I’ve been learning KiCad to move into hardware design and better understand systems beyond software.
